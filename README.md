- Movement or interaction stops after entering a boat.

## 🛠️ Troubleshooting — Step by Step

1. **Update before reproducing.** The October 28 patch addressed a boat-entry freeze; verify the game is fully updated.
2. **Try normal controls first.** Check the game’s interaction and exit prompts rather than forcing repeated input.
3. **Avoid overwriting progress.** If you have a usable save, preserve a backup before resetting the session.
4. **Restart the session.** If the game remains frozen, close it normally when possible, relaunch and test the same boat interaction.
5. **Describe the conditions.** Report whether the softlock happens only in co-op, at a specific boat or after another action.
